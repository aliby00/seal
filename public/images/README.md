# SEAL — visual assets

The interface no longer uses photographs. The scanner, the curtain and the x-ray
bags are drawn in SVG from the same geometry as `brand/v3/gen/marks.mjs`
(`src/app/components/brand.tsx`). Icons and the share image live in `src/app/`
(`icon.svg`, `apple-icon.png`, `opengraph-image.png`).
